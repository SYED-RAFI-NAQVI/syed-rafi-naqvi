My first interactive personal portfolio website, deployed in **September 2019**. Built as a clean, single-page landing site to host my resume and link to my various professional social profiles (GitHub, LinkedIn, Medium).

## ✨ Features

- **Interactive Canvas Background:** Uses `particleground.js` to render a dynamic, network-like particle background that reacts to mouse movement.
- **Responsive Layout:** Simple, centered flex-style layout that works seamlessly across desktop and mobile devices.
- **Social Integration:** Uses FontAwesome icons to link out to professional networks.
- **Resume Hosting:** Directly serves my resume (`deedy.pdf`) with a custom UI icon.

## 🛠️ Built With

- **HTML5 & CSS3**
- **JavaScript**
- **Particleground.js** (Canvas particle animation)
- **FontAwesome** (Vector icons)
